Belihuloya XVI broadcast setup

1Choose a setup

There are two pages. control.html is the operator panel — the audience never sees it. overlay.html is the clean graphic that OBS puts on top of the camera. The two pages must share the score, and how they share it decides which setup you use.

Use on match day

A · Local laptop

The scoreboard runs from the project folder on the streaming laptop at http://127.0.0.1:4173.

  • Works with no internet (only Facebook needs it)
  • Control panel can be in Chrome, full screen, on a second monitor
  • Upload Media button works (MP4 logo videos)
  • Score survives a laptop or server restart
  • Needs Node.js installed on the laptop
Optional

B · Hosted on Vercel

The same pages on a public link like belihuloya-xvi.vercel.app.

  • No install — any laptop with OBS can use it
  • Easy to share a preview link with the organising committee
  • Control panel must run inside OBS (see step 6)
  • No Upload button — videos go in public/media before deploying
  • Pages load from the internet
Why the difference

Locally, a small sync server on the laptop passes every score change from Chrome to OBS instantly. Vercel only serves files, so the two pages can talk only when they are open in the same browser — and OBS has its own browser, separate from Chrome.

2Start the scoreboard

Setup A. Do the first-time part once, a day before the event, while you still have internet.

First time only

  1. Install Node.js LTS from nodejs.org (version 20 or newer). Keep the default options.

  2. Copy the project folder Belihuloya xvi live to the streaming laptop, or clone it:

    git clone https://github.com/Sahancoder/Belihuloya-xvi.git

  3. Double-click start-scoreboard.bat. The first run installs packages, which takes a few minutes.

Every match day

  1. Double-click start-scoreboard.bat in the project folder. A black window opens and the control panel opens in your browser.

    Keep the black window open for the whole event. Closing it stops the scoreboard.

  2. Press F11 in the browser to make the control panel fill the screen.

  3. Check the header shows a green OBS Sync Online light. Yellow Local Tab Sync means the server is not reachable — see Troubleshooting.

If the black window says port 4173 is busy, an old scoreboard window is still open. Close every other terminal running the project, then start again.

  1. In Match Live, click + under Sources → Video Capture Device → name it Camera.

  2. Pick the camera or capture card, set Resolution/FPS Type to Custom and 1920x1080. Click OK.

  3. Right-click Camera → Transform → Fit to screen.

Transparent in OBS, dark in a browser

The overlay stays see-through only inside OBS. Open in Chrome it shows a dark background so you can check it. To force transparency anywhere, add ?transparent=1 to the URL.

Audio

  1. Add a mic: + → Audio Input Capture → pick the microphone.

  2. In the Audio Mixer, set Scoreboard Overlay around −12 dB so interval music sits under the commentary.

  3. To hear the music yourself: click the mixer's ⋮ → Advanced Audio Properties → set Scoreboard Overlay to Monitor and Output.

4Run the match

The whole match is run from the control panel. What OBS shows follows the status buttons in the header.

READYWaiting screen with both universities and “Starting soon”.
LIVECamera with the score strip at the bottom.
INTERVALFull-screen loop: logo animation, break image or video, with music.
FINISHEDResult screen with runs, balls, outs and the winner.

One match, start to finish

  1. Select teams. Click Team A, pick a university from the list or search; do the same for Team B. The same university cannot be picked twice.

  2. Choose the batting team. Tap its card in Live Score Control. The green BATTING tag moves on the overlay.

  3. Press LIVE in the header when play begins.

  4. Score with the buttons or the keyboard (below). Every change reaches OBS immediately.

  5. End Current Turn when the side is done. Confirm; that team's score locks and batting switches to the other team.

  6. Break? Pick a screen in Interval / Break Media and press Play Loop. Press Stop → Live to return.

  7. Finish Match shows the result. Winner rule: Auto (most runs) or pick the winner by hand.

  8. New Match saves this match to the Match Log, clears the scores and sets READY for the next pair of teams.

Shortcuts pause while a dialog is open or you are typing in a box. Reset Match asks you to type RESET.

Interval videos and music

  • Your own logo video: press Upload and choose an MP4 named susl-logo.mp4, belihuloya-logo.mp4 or sponsors.mp4. It replaces that built-in animation and loops. Any other MP4 name appears as its own item in the list.
  • Music: Music On loops Driving.wav during INTERVAL. Uploaded videos play their own sound instead.
  • Music plays from: keep OBS overlay for the stream. Choose This laptop only when testing without OBS — browsers block sound in a tab you have not clicked.

Where to put the control panel

Best: Chrome on a second monitor, full screen with F11, and OBS on the laptop screen. On one screen, use Alt+Tab to switch, and watch the OBS Output Preview on the control panel instead of OBS.

6Host on Vercel

Setup B. The project already contains vercel.json, so Vercel builds it with no extra settings.

Deploy from GitHub

  1. Push the latest code to github.com/Sahancoder/Belihuloya-xvi.

  2. Sign in at vercel.com with GitHub → Add New… → Project → import Belihuloya-xvi.

  3. Framework Preset shows Vite; Build Command npm run build; Output Directory dist. Click Deploy.

  4. You get a link such as https://belihuloya-xvi.vercel.app. Every later push to GitHub redeploys it.

Or deploy from the laptop

# in the project folder
npx vercel login
npx vercel          # preview link
npx vercel --prod   # main link

Connect OBS to the hosted pages

Important

Do not run the control panel in Chrome with Setup B. OBS will not see the changes. Both pages have to live inside OBS.

  1. Scoreboard Overlay source: set URL to https://your-project.vercel.app/overlay.html, with the same properties as in step 3.

  2. Control panel as a dock: Docks → Custom Browser Docks… → name Score Control, URL https://your-project.vercel.app/control.html → Apply.

  3. Drag the dock's title bar out of the OBS window to float it, then resize it to fill the second monitor.

  4. Test before every event: press +1 in the dock. The overlay in the OBS preview must change within a second.

If the dock test fails

Some OBS versions keep docks in a separate browser storage from sources. Use the Score Panel scene instead, which is guaranteed to share with the overlay:

  1. In the Score Panel scene add a Browser source named Score Control: URL …/control.html, Width 1920, Height 1080.

  2. Right-click it → Interact. Maximise the Interact window and operate the match there. Stay on the Match Live scene for the stream.

Videos on Vercel

Put MP4 files in public/media/ — for example public/media/susl-logo.mp4 — then commit and push. They appear in the Interval list automatically. Keep each video under about 50 MB.

Is a public link safe?

Yes. Anyone can open the link, but the score lives in the browser that opened it. A visitor pressing buttons changes only their own copy, never the OBS on your laptop.
